🚀 Speeding it up: local or cloud model

First, a measured fact: on this Mac the RVM model runs at ~36 fps but the whole pipeline ran at 8.4 fps. A faster model alone would barely help. The biggest win we measured came from removing PNG files, which gave ≈2.1× end-to-end. See the Performance page.

🎥 Hosted keying APIs/editorsZero setupLess control than this repo; footage leaves your machine

🎯 Recommendation

  1. Use key_fast.py now (free, already 2× faster).
  2. Trim to the sections you keep.
  3. Only go to cloud/CUDA when you have many long clips or need MatAnyone's hair quality. We have not benchmarked any cloud service, so measure one on a single clip before committing.
