💡 Recommendations

Ranked by how much each would improve the result.

🥇 Run the full 137 s clip
Only 12 s was processed. At ~8 fps the full take is about 17 minutes. Use -ss/-t per section for the parts you keep.
🥈 Tune downsample ratio per shot
Soft or blobby edges: raise toward 0.5. Background bleeding through: lower it. This is the one real knob.
🥉 Light the screen evenly
The chroma half of the hybrid depends on it. Even lighting plus distance from the screen cuts spill at the source.
🎨 Match the background
Blur, colour temperature and light direction of the background should match the person. A light-wrap pass would blend edges further.
🔤 Add captions
Transcribe with Whisper and render as Remotion text for Shorts.
🧪 Benchmark before trusting it
Test on 3 to 5 different clips (hair, props, fast motion) before relying on it for a client.
🏆 Hybrid with Resolve for hero shots
Export the RGBA from here, finish edges and grade in Resolve.
🖥️ CUDA box? Try MatAnyone
Better hair and fast-motion detail than RVM.
