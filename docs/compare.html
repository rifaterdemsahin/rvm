⚖️ Why this beats a manual Resolve green-screen key

Resolve's 3D Keyer and Delta Keyer are excellent tools. The argument here is not "better pixels on every shot". It is fewer ways to get it wrong, because a model and a script replace a pile of hand-tuned nodes.

✅ Where this approach is less error-prone

Issue🎛️ Resolve keyer🤖 RVM + chroma hybrid
🔁 ReproducibilityNode tweaks live in a project; easy to drift between clipsOne script, versioned in git. Same input → same output
🟩 Uneven lighting / screen wrinklesColour key breaks at shadows and hot spots; needs garbage mattesRVM segments the person, so screen colour variation barely matters
👕 Green-ish or dark clothingKeys holes into the subjectChroma key can't punch holes where RVM says "solid" (max() rule)
⚡ FlickerPer-frame colour threshold flickers on noiseRVM carries recurrent state across frames, so the matte is temporally stable
🪄 SpillSeparate despill node, easy to forget or overdoDespill is built into the pipeline for every frame
📦 Batch / automationManual per clip; scripting is limitedFully scriptable: drop clips in, get composites out, CI-able
🧾 AuditabilityHard to diff a node graphParameters are plain code; git diff shows every change
💸 CostFree tier is fine, but keyer quality gating and hardware varyFree, open-source (RVM is GPL-3.0), runs on a laptop at ~8 fps

🧭 The honest trade-offs

🏆 Resolve still wins for hair-level fine detail on a perfectly lit screen, for colour grading, and for hand-finishing a hero shot.
🤖 RVM can miss props (mug, pen) and slightly blur very fast arm motion. The chroma half of the hybrid catches most of this; MatAnyone is better on CUDA.
🧪 Verified here only on one 12 s clip. The reliability claims above come from how the method works, not from a benchmark across many shots.

🎯 Bottom line

Use this pipeline when you need consistent results across many clips with no hand-tuning. Keep Resolve for the final polish on shots that matter most. The two combine well: export the RGBA from this repo, then drop it above your background in Resolve.
