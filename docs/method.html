🧪 Method

🧠 1. Matte with RVM

Robust Video Matting is a recurrent network: hidden state carries between frames, so the matte stays temporally stable (less flicker than per-frame models). We use MobileNetV3 on MPS with downsample_ratio=0.4, which preserves fingers and hair edges at 1624×1080.

🟩 2. Chroma-key refinement

RVM is trained on people and can leave soft halos. A green-dominance key, greenness = G − max(R, B), is thresholded to a soft alpha. Where RVM is confident the pixel is foreground (>0.98) we take the larger of the two (fills holes); elsewhere we take the smaller (removes green fringe).

🪄 3. Despill

Remaining green reflections on skin and arms are removed by clamping G to the average of R and B.

✂️ 4. Edge cleanup

0.8 px Gaussian on alpha, then a levels remap (0.05–0.95) to crush noise while keeping a soft edge.

🎞️ 5. Compose in Remotion

The transparent WebM is layered over a gently zooming, slightly blurred background to fake depth of field, with contrast/saturation grade, drop shadow, vignette, and fades. Audio comes from the source clip.

▶️ Run it

python3.12 -m venv .venv && source .venv/bin/activate
pip install torch torchvision av tqdm numpy pillow opencv-python-headless
python key.py work/clip.mp4 work/frames
ffmpeg -framerate 30 -i work/frames/%04d.png -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 20 public/fg.webm
npm install && npm run render

⚠️ Known limits

Held props can be missed by RVM; fast hand motion blurs edges slightly; chroma key assumes even lighting on the screen.
