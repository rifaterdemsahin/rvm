Architecture

End-to-end flow, from the newest file in Downloads to the deployed page.

1 · Source~/Downloads/2025-10-26-06-33.mp4 · 1920×1080 @ 60 fps, pillarboxed
▼
2 · Prep (ffmpeg)trim 12 s · crop black bars (cropdetect) → 1624×1080 · 30 fps
▼
3 · key.py (PyTorch / MPS)RVM MobileNetV3 matte (recurrent, downsample 0.4) + chroma key (G − max(R,B)) merged → soft alpha · average despill
▼
4 · Encode (ffmpeg)RGBA PNG sequence → transparent VP9 WebM (yuva420p) · audio → m4a
▼
5 · Remotion compositionbackground.jpg (push-in, depth blur) + fg.webm + vignette + audio → output.mp4 (H.264)
▼
6 · GitHub Pages/docs served as static site · shared menu.js nav
